# SecureMarket

## Project Overview

A secure back-end marketplace REST API where sellers list products with images, buyers browse and purchase them, and administrators manage the platform. The system handles order processing with server-side price integrity, invoice and export file generation, product image management via filesystem operations, and role-based access control across three roles (Admin, Seller, Buyer).
